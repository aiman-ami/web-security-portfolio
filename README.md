# Web Security Portfolio

A daily, hands-on log of my progress learning web application security, working through PortSwigger's Web Security Academy alongside foundational Linux, Git, Bash, and JavaScript skills.

## About this repo

I am working toward a career in bug bounty hunting and web application security. This repository is both a personal study log and a public record of that progress, documenting what I learn, how I solve each lab, and why each technique works, not just the payload that worked.

## Structure

- **Roadmap.md** - the overall learning plan, organised by topic and target skill level, tracking what has been covered and what is still ahead
- **day-NN.md files** - a dated entry for each study session, covering what was done that day: labs solved, payloads used, and a plain-language breakdown of the underlying vulnerability and why the solution works
- **linux-cheatsheet.md** - reference notes on Linux commands, shell syntax, and command-line tools, built up as new commands are learned
- **xss-cheatsheet.md** - a pattern-based reference for identifying where user input lands on a page and choosing the right payload for that context, built from PortSwigger's XSS labs

## How I work through each lab

For every lab, I aim to understand three things before moving on: what the vulnerability actually is, why the specific payload used exploits it, and how to recognise the same pattern elsewhere. The day notes reflect that approach, they are written to explain reasoning, not just to record a solved checklist.
